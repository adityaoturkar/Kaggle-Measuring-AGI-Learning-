## What I'm Building

**[Kaggle — Measuring AGI Learning](https://github.com/adityaoturkar/Kaggle-Measuring-AGI-Learning-)**

A submission to Kaggle's AGI benchmarking competition, focused on designing rigorous cognitive benchmarks to measure how AI systems acquire and retain knowledge. Measuring intelligence is one of the hardest open problems in AI — this project is my attempt to engage with it seriously.
